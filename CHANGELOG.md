# Changelog

All notable changes to NekoRay will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Modern C++23 support
- Qt 6 compatibility and optimizations
- CI/CD pipeline with automated testing
- Code style guide and contribution guidelines
- Security policy documentation
- EditorConfig for consistent code formatting
- Enhanced clang-format and clang-tidy configurations

### Changed
- Upgraded minimum CMake version to 3.28
- Updated default Qt version to 6.5+
- Modernized C++ standard from C++17 to C++23
- Improved build system configuration
- Updated GitHub Actions workflows

### Fixed
- Removed deprecated Qt 5 attribute calls
- Cleaned up legacy code patterns
- Fixed icon theme fallback handling

### Deprecated
- Qt 5 support (use v3.26 or earlier)
- C++17 standard (C++23 now required)
- CMake versions below 3.28

### Removed
- Legacy Qt 5 compatibility code
- Outdated build configurations

### Security
- Added security scanning to CI/CD
- Implemented CodeQL analysis
- Enhanced input validation guidelines

## [3.26] - 2023-12-09

### Added
- Core functionality improvements
- UI enhancements
- Bug fixes and stability improvements

---

## Notes

- Versions prior to 3.26 are not fully documented in this changelog
- For detailed release notes, see GitHub Releases
- Breaking changes will be clearly marked
